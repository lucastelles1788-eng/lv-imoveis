# L&V Negócios Imobiliários — protótipo

Site inicial estático, responsivo, com identidade visual e formulário de demonstração.

## Publicação
Envie `index.html` e `logo-lv.png` ao repositório GitHub. Pode publicar como site estático via GitHub Pages, Vercel ou Netlify.

## Importante
O cadastro atual usa localStorage: os imóveis **não** são compartilhados entre dispositivos. Não há login, segurança de administrador, Supabase, upload de fotos ou domínio conectado nesta versão. Essas funcionalidades exigem uma etapa posterior de implementação e configuração.

## Logo
O arquivo `logo-lv.png` foi recortado de uma captura de tela enviada pelo usuário. Substitua-o pelo PNG original quando disponível para maior qualidade.
